# KHdownloaderPlus
A short little python script I made and tweaked every once in a while for a few weeks to give me a quick and easy way to download entire albums at once from KHinsider.
I achieved very fast speeds using python async libraries. I was careful to put max semaphores on it because I think I was at one point Denial of Servicing their servers (Im so sorry, i didnt mean to!!) because I was trying to pull down so many files at once.

I also included a slightly older but working version of the script that I made a frontend for using Flask
